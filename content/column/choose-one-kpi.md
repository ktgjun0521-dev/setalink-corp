追う数字が10個も20個もあると、どれも大事に見えて、今週なにを変えるかが決まりません。数字が足りないのではなく、多すぎて決められない状態です。ここでは、今月追う数字を1つに絞る手順を、順番にお伝えします。

## KPIが多すぎると、なぜ現場は動けなくなるのか

KPI（目標に向けて追いかける数字）は、気になることが出るたびに足されます。減らす機会は、なかなかありません。

数字が増えると、次の3つが起きます。

- 集計に時間がかかり、数字が出るころには状況が変わっている
- 会議が数字の読み上げで終わり、今週なにを変えるかが決まらない
- 現場は、結局いままでどおり「たぶん」で動く

セタリンクの支援事例にも、数字が増えて集計が重くなっていた例があります。人材会社の例では、営業日報のExcelが大きくなり、指標が増えるたびにタブと集計が増えて、売上を確認するだけでも時間がかかっていました（[支援事例](/cases)）。

数字を決めること自体が難しいことは、DX（デジタルを使った業務や事業の変革）についての調査にも表れています。IPA（情報処理推進機構）の[「DX動向2026」](https://www.ipa.go.jp/digital/chousa/dx-trend/dx-trend-2026.html)によると、DXに取り組む企業のうち、DXの成果を測る指標を「設定している」のは23.9%でした。設定していない企業が挙げた理由で最も多かったのは「評価指標の設定方法がわからない」の36.0%です。

指標を決められない会社と、数字が多すぎる会社。困りごとは逆に見えますが、根は同じです。どの数字で何を決めるかが、決まっていません。

## 今月追う数字は、どういう手順で選ぶのか

次の順番で選びます。

1. **目標を1つ書く。** 今期の売上、来月の新規契約数など、いちばん上の目標を1つだけ書きます。
2. **目標までの流れを、段階に分ける。** 問い合わせ → 商談 → 契約 → 継続、のように並べます。
3. **段階ごとの数と、次へ進んだ割合を並べる。** 最初は、手元のおおよその数でかまいません。
4. **いちばん落ちている所を1つ選ぶ。** そこが、いま成果を止めている所（ボトルネック）の候補です。割合が低くても、もともとそういう水準の段階もあるので、以前の自社の数字とも比べます。
5. **現場の行動で動かせる数字に言い換える。** 「契約率」ではなく「商談の翌日までに見積もりを出した件数」のように、今日の動きに直します。
6. **1か月追って、測り直す。** 動いたら、次に落ちている所へ移ります。

この手順は、セタリンクが支援で使っている改善の流れ（仮説を立てる → 数字をそろえる → ボトルネックを見つける → 施策を実行する → 成果を測る）を、数字選びに当てはめたものです。

たとえば、体験から入会につなげる多店舗のサービスで考えます。下の数字は説明のための計算例で、実在の会社のものではありません。

| 段階 | 人数 | 前の段階から進んだ割合 |
|---|---|---|
| 問い合わせ | 200人 | － |
| 体験の予約 | 120人 | 60% |
| 体験に来店 | 60人 | 50% |
| 入会 | 36人 | 60% |

この計算例では、予約から来店に進む割合が50%で、いちばん落ちています。今月直すのは、この割合です。現場が毎週追う数字は、行動に言い換えた「予約の前日に確認の連絡を入れた件数」などにします。入会数や売上は結果として出る数字なので、追う数字にはしません。

## 追う数字と、見るだけの数字は、どう分けるのか

1つに絞るといっても、ほかの数字を捨てるわけではありません。役割を分けます。

| 確かめること | 追う数字 | 見るだけの数字 |
|---|---|---|
| 現場が自分の行動で動かせるか | 動かせる | 結果として出る |
| どの間隔で確かめるか | 毎日〜毎週 | 月に1回 |
| いま、流れのどこにあるか | いちばん落ちている所 | それ以外の所 |
| 数 | 1つ | 2〜3個 |

売上、利益、契約数は「見るだけの数字」に置きます。月に1回、追う数字を動かした結果として確かめます。

## 絞るときに、つまずきやすいのはどこか

手順は単純ですが、つまずきやすい所が3つあります。

- **結果の数字を選んでしまう。** 売上や契約数を追う数字にすると、現場は何を変えればよいかが分かりません。
- **絞ったあとも、全部の数字の報告を求める。** 報告の手間が減らず、追う数字が埋もれます。見るだけの数字は、月に1回の確認にとどめます。
- **画面や集計表から作り始める。** 先に決めるのは、どの数字で何を決めるかです。

セタリンクの進め方では、支援を5つの段階（問いの整理 → 定義 → 入力・集計 → 画面 → 運用）で進めます。追う数字を絞るのは、最初の「問いの整理」にあたります。ここが決まると、そろえる定義も、集める数字も、画面にのせる数字も少なくて済みます。

## セタリンクの進め方では、最初に何を聞くのか

私たちは、「どんなダッシュボードが欲しいですか？」からは始めません。会社の方針から、見るべき数字と現場の行動まで、逆にたどって組み立てます。初回の相談では、次の5つを伺います。

- いま、事業を伸ばすうえで一番改善したいことは何か
- いまは、何を見て判断しているか
- その数字を見て、実際に何を変えているか
- 見えなくて困っていることは何か
- もしそこが見えたら、何を変えたいか

3つ目で答えに詰まる数字は、追う数字の候補から外してよい数字です。見ても行動が変わらないからです。

先ほどの人材会社の支援では、営業の指標を重要度で整理し、毎日確認する指標を日別の画面にまとめました。日々の判断ができるようになり、目標達成率は約10%上がっています。これはセタリンクの支援事例の数字で、同じ結果をお約束するものではありません。

セタリンクがつくるのは、現場に何を追わせるかを、数字で決められる状態です。

## 絞った数字は、いつ見直すのか

月に1回です。流れの表を作り直し、直すと決めた割合が動いていたら、次に落ちている所へ移ります。動いていなかったら、行動への言い換えが合っていたかを見直します。

1つに絞るのは、ずっとその数字だけを見るためではありません。落ちている所を、順番に直していくためです。自社の流れで整理してみたいときは、[60分の無料相談](/contact)でお話を伺います。

業種ごとに、数字を整えたあと何が変わったかは、[支援実績・事例](/cases)でご紹介しています。
