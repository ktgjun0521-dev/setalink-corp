会議で、店舗から上がってきた売上と、経理の売上と、本部の資料の売上が、少しずつ違う。どれが正しいのかを確かめているうちに、会議の時間が終わってしまう。よくある場面です。ここでは、売上の数字が資料ごとに合わなくなる理由と、ずれを見つけて直す手順をお伝えします。

## 売上の数字は、なぜ資料ごとに合わなくなるのか

ずれ方には、2つの種類があります。

- **決まりの違い**：どの資料も、その資料の決まりの中では正しい。ただ、「売上」に何を含めるか、いつの売上として数えるかが、資料ごとに違う
- **写し間違い**：元の記録から別の表へ、人が数字を写すときに、打ち間違いや貼り間違いが入る

先に疑いたいのは、1つ目です。たとえば、ある店舗の11月の売上を、3つの資料で見てみます。数字は説明のための計算例で、実在の会社の数字ではありません。

- 店舗の報告は、税込で、返品を引く前。1,100,000円
- 本部の集計は、税抜で、返品を引く前。1,000,000円
- 経理の数字は、税抜で、返品を引いた後。950,000円

店舗の報告と本部の集計の差100,000円は、税込と税抜の違いです（税率10%で計算）。本部の集計と経理の数字の差50,000円は、返品を引いたかどうかの違いです。3つとも、計算は間違っていません。決まりが違うだけです。決まりをそろえれば、同じ数字になります。

## ずれを生む原因には、どんなものがあるのか

よく出てくる原因は、次の6つです。

| 原因 | 資料ごとに違うこと | たとえば |
|---|---|---|
| 日付の区切り・締め日 | 1日をどこで区切るか、月をいつで締めるか | 閉店後に入った売上を、その日にするか翌日にするか。末日締めか、25日締めか |
| 税込か税抜か | 税を含めるか | 店舗は税込、経理は税抜 |
| 返品・値引き | 引くか、いつ引くか | 返品を、売った日から引くか、返品を受けた日から引くか |
| 売上にする時点 | 申し込み・利用・入金のどこで数えるか | 前払いの会費を、受け取った月にするか、利用する月にするか |
| 集計の範囲 | どの店舗・商品・売り方を含めるか | ネット販売や物販を、店舗の売上に入れるか |
| 手で写すときの間違い | 決まりではなく、作業の間違い | 桁の打ち間違い、数字の入れ替え、貼る行のずれ |

業種によって、出やすい原因は変わります。多店舗のフィットネスなら、前払いの会費や入会金を、いつの売上にするか。ネット通販（EC）なら、注文の日と出荷の日のどちらで数えるか、キャンセルや返品をいつ引くか。人材紹介なら、入社が決まった月か、請求した月か、入金があった月か。どれも「売上にする時点」の違いです。

## ずれは、どういう手順で見つければよいのか

月の合計を何度も見比べても、原因はなかなか見つかりません。次の順番で、差が出ている所を絞っていきます。

1. **比べる資料を2つに決め、期間と範囲をそろえる。** 3つ以上を一度に比べず、まず2つを並べます。同じ店舗、同じ期間にそろえます。
2. **差を出す。** 2つの数字の差を、金額で出します。
3. **差の出方から、原因の当たりをつける。** 差の大きさや、差が出るタイミングを見ます。
4. **日ごと・店舗ごとに分けて、差が出る所を絞る。** 月の合計では合わなくても、日ごとに並べると、差が出ている日は数日に限られることがよくあります。
5. **絞った所の明細を、1件ずつ突き合わせる。** レジの記録や請求の記録など、1件ずつの記録で確かめます。
6. **原因と、どちらの決まりにそろえるかを書き残す。** 同じずれを、来月また探さないためです。

3つ目の当たりのつけ方は、次のとおりです。あくまで目安なので、最後は明細で確かめます。

- 差が、売上のほぼ1割 → 税込か税抜か（税率10%の商品が中心の場合）
- 月初・月末の日に差が集まる → 日付の区切り・締め日
- 返品の多い日に差が出る → 返品・値引き
- 前払いの多い月に差が大きい → 売上にする時点
- 一部の店舗・商品だけ差がある → 集計の範囲
- 差が9で割り切れる → 手で写すときの間違い（数字の入れ替え・桁のずれ）

最後の目安は、帳簿の確かめで使われる方法です。隣り合う数字を入れ替えたり（1,250を1,520と書くなど）、桁を1つずらしたりすると、差は9の倍数になります。偶然9で割り切れることもあるので、当たりをつけるためだけに使います。別の数字を打った、貼る行がずれた、という写し間違いは、9で割り切れるとは限りません。

## 見つけたずれは、どう直せばよいのか

直すのは、数字ではなく決まりです。合わない分を手で調整して合わせても、来月また同じずれが出ます。

決まりは、1枚の表に書き出します。書くことは次のとおりです。右の列は書き方の例で、どれが正しいかは会社によって違います。

| 決めること | 書き方の例 |
|---|---|
| 1日と1か月の区切り | 1日は閉店時刻で区切る。月は末日で締める |
| 税 | 社内の資料は、税抜でそろえる |
| 返品・値引き | 返品は、返品を受けた日の売上から引く |
| 売上にする時点 | 前払いの会費は、利用する月の売上にする |
| 範囲 | ネット販売は、店舗の売上と分けて数える |
| 元にする記録 | 売上はレジの記録から集め、人が打ち直さない |

大事なのは、どの資料も同じ決まりで作られることです。決算や税の申告に使う数字の決まりは、経理や会計の専門家と確かめてください。

セタリンクの進め方でも、売上などの言葉の決まりをそろえるのは「定義」の段階で、数字を集める仕組みを作る前に行います。順番が逆だと、ずれごと自動で集めることになるからです。

表の最後の「元にする記録」は、写し間違いを減らすための決まりです。人が数字を写す回数が減るほど、ずれが入る所も減ります。

セタリンクが支援した全国展開のフィットネスクラブでも、売上の記録そのものは、各店舗のレジ（POS）で取れていました。ずれが入っていたのは、その先の集計です。手作業でまとめていたため、帳簿と合わないことや、費用を違う分類に入れてしまうことが続いていました。

そこで、基幹システム（会社の中心の業務システム）とレジのデータをつなぎ、正しい数字が毎日自動でそろう形にしました。人が数字を写す場面がほとんど無くなり、業績管理のための入力作業はほぼゼロです。店長ミーティングや経営会議でも、店舗別・スタッフ別の売上を材料に、決めやすくなっています（[支援実績・事例](/cases)）。

## 決まりをそろえ終わるまで、会議ではどう扱えばよいのか

決まりをそろえるには、時間がかかることがあります。そのあいだは、次のようにします。

- 数字の横に、決まりを短く書き添える（「税抜・返品を引いた後・末日締め」など）
- 会議ごとに、使う資料を決めておく（経営の会議は経理の数字、店舗の日々の確認はレジの数字、など）
- 原因が分かっている差は、会議の場で数字を合わせ直さない

数字を見て決める時間を、数字を合わせる時間に取られないようにするためです。
